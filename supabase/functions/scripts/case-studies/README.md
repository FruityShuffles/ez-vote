# Case Study fixtures

One JSON file per case study — a completed, publicly viewable election that teaches one
voting-theory lesson. Seeded into the database by `../seed-case-studies.ts`
(`deno task seed-case-studies`) and asserted offline by `../case-studies.test.ts`.

Format, the identity/idempotency rules, and how to add one:
**`docs/Features/Case Studies.md`**.
